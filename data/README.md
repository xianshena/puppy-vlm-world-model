两套复核均使用 Python 标准库。从此目录运行：

```shell
python -B "视觉记忆复算包/03_复算/verify.py"
python -B "下一步观察练习/复核练习.py"
```

第一条从正式逐步回答重算成绩。第二条检查输入／目标配对、全部归档图像的字节哈希和可见历史相同但后果不同的样本数。回合和图像名称里含情境、地点或可见性信息，训练时只向模型提供相应时刻允许的观测与动作。
