# 小狗的视觉记忆 · 正式回合复算数据

同一个 Qwen3-VL-8B-Instruct（Q4_K_M）在三个可以检查的地点找蓝球。权重固定，只改变它在决策前能读到的记忆。程序渲染第一视角画面，动作最多三次。211 个正式布局各有四种经历，共 844 个回合、4,431 条策略轨迹和 23,004 次模型调用。

## 怎么读一行

用 Python 的 `gzip.open(文件, "rt", encoding="utf-8")` 打开，每行是一个完整回合。例子 `1000-stay` 表示第 1000 号布局、球留在原处。A 是桌子，B 是沙发，C 是柜子，H 是出发时所在的大厅。

| 字段 | 内容 |
|---|---|
| `initial`、`target` | 模拟器中球的初始地点和正式决策时的真实地点，供判分。 |
| `history` | 12 个历史时间点的视角、帧引用以及 VLM 读图回答。原实验把 JPEG 像素发给模型。文件名含渲染标签，复用此数据做预测时只能给模型像素和当时允许的观察。 |
| `records`、`keyframes` | 结构化观察记录和检索到的历史帧序号。 |
| `steps[策略]` | 本策略实际走过的步骤及其顺序。有效动作有 `action`、`frame`、`observed` 和 `found`；无效动作记为 `action: null`，该局随即结束。 |
| `calls` | 本局实际发出的请求。每条保留当时的完整文字提示、输入图片名、模型逐字回答、输入/输出 token 及本次耗时（秒）。 |
| `source_episode_sha256`、`final_view_sha256` | 原始逐局文件哈希，以及决策出发画面的 JPEG 哈希。可核对反事实两侧当前画面是否相同。 |

例如，在 `1000-stay` 中查 `calls["full_history:action:0"]["raw"]`，能直接读到第一次选择的原文 H。查 `calls["initial_compaction:9"]["raw"]`，可看到模型是怎样经过一张空大厅图就改写了旧记忆。行动后写入的键如 `single_action_compaction:write:0`，对应的提示中保留了写入前的状态和刚收到的观察。

## 怎么对照

- 原地（`stay`）、目睹移动（`seen`）和背后移动（`unseen`）各有六种策略。反事实（`counterfactual`）保持路线和当前大厅画面相同，改变先前目击地点，检查三种文本记忆策略。每个条件都有 211 个布局。
- `first_correct` 是第一步查对的比例，`success` 是最多三步查到的比例。两张表中，第一张存比例和均值；第二张存整数分子和分母。配对得分要求同一布局里原处和反事实两边的第一步都查对。
- 原处条件下，完整文字历史组的 211 次首答中，有 182 次答了 H 而终止，29 次答了合法地点且找对。格式和选择结果一起影响了得分。结构化物体记录在同条件下 211 次首选全对，球在背后被移走时则首选全错。这些数据测的是三个离散地点中的找物行为。
- `max_action_prompt_tokens` 是先取每局决策峰值，再按布局求均值。`total_model_tokens` 和 `total_model_seconds` 包含决策及该策略的记忆写入。共享的 4,510 次视觉识别调用单列在数据中。完整历史组很多局提前终止，比较成本时须同时查看步数和无效动作率。

## 重算

在本目录执行：

```console
python -B "03_复算/verify.py"
```

脚本核对正式数据的压缩与解压 SHA-256，重新解析每一步原始回答、比对模拟器真值与反馈，逐字段重算两张 CSV，并输出非法回答和配对汇总。先导布局 0 和 1 的 221 条调用已在导出时排除。

如持有已取回的完整实验目录，可用 [导出程序](03_复算/export.py) 按其原始回执验证来源，再重新提取同样的正式数据。来源表保留了原始请求、冻结计划、原始报告、实验及场景生成器的 SHA-256，逐局文件哈希随各回合保存。
